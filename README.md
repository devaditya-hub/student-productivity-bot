#Student Productivity Tracker Bot
This is a simple python project designed for students to log this study streaks.

##The bot tracks:
- study entries(date, subject and hours )
- tasks completed
- productivity score
- and final end goodbye to end the bot.
  
All the data is saved in text files so the user cannot forget its study tracking history.

##Features
-add study logs with date , subject and hours.
-add tasks done 
-get the productivity score based on your study logs and task done
-data stored permanently in "study.txt" and "task.txt"

## Technologies Used
-Python 33
-File handling (text files)

## How it works
when user selects:
1 > Add Study Entry
   program asks :
   Date(DD_MM_YYYY)
   Subject:
   Hours studied:
  Entry is saved to study.txt
2 > Add Task Done
   program asks:
   Enter task done:
3 > View Score
   program reads both files, counts values and prints:
   Total study hours
   Total tasks completed 
   Productivity score
4 > EXIT
   program Stops.
